# 📚 Security Learning

My learning approach is heavily hands-on:

```text
Learn
  ↓
Understand the vulnerability
  ↓
Reproduce it in a controlled lab
  ↓
Analyze the request / response
  ↓
Understand the root cause
  ↓
Document the finding
  ↓
Study mitigation
  ↓
Build something around it
```
